## What it is

Derive is one HTML file that runs on desktop and phone. It has 17 units. The first 16 follow the NeetCode 150 topics, with 5 exercises per lesson.

There are four kinds of exercise: spot the pattern, fill the gap, trace the code and find the bug. Hearts, XP and streaks keep score. Spaced repetition brings a lesson back after 1, 3, 7 and 14 days.

## Keeping it correct

An eval suite checks that all 150 problems are covered. It also re-runs every trace and gap card. Each step-through visualization is recorded from a real run of the algorithm.
